# Выбор модели для MITS

> Дата исследования: Январь 2026
> Целевое оборудование: RTX 2080 (8GB VRAM) + 32GB RAM

## Требования к модели

Система MITS — сократический репетитор для технических дисциплин:
- Математика (алгебра, анализ, геометрия)
- Программирование (Python, алгоритмы, структуры данных)
- Физика
- Химия
- Биология

### Ключевые критерии:
1. **Качество STEM-рассуждений** — способность решать задачи и объяснять
2. **Сократический метод** — задавать вопросы, а не давать ответы
3. **Размер модели** — должна работать на 8GB VRAM
4. **Возможность дообучения** — QLoRA fine-tuning на consumer GPU

### Детальный анализ лидеров

#### 1. Qwen3-8B (Рекомендуемая для STEM)
**Источник:** [Qwen3 Technical Report](https://arxiv.org/pdf/2505.09388)

**Преимущества:**
- Лучшие показатели по MMLU (76.89) и GPQA среди 8B моделей
- Отличный баланс между математикой, наукой и программированием
- Хорошо переносит квантование (quantization-tolerant)
- Поддержка длинного контекста (32K)
- Активное сообщество и документация

**Бенчмарки:**
```
MMLU: 76.89
GPQA: 44.44 (base) → 63.3 (с RL)
GSM8K: 89.84
MATH: 60.80
EvalPlus (coding): 67.65
```

#### 2. Nemotron-Cascade-8B-Thinking (Лучшая для математики)
**Источник:** [NVIDIA Research](https://research.nvidia.com/labs/nemotron/nemotron-cascade/)

**Преимущества:**
- Рекордные 90.5% AIME 2024 (сравнимо с DeepSeek-R1 671B!)
- Специально обучена на математических рассуждениях
- Отличный coding (71.1% LiveCodeBench)

**Недостатки:**
- Генерирует длинные chain-of-thought (больше токенов)
- Может быть избыточной для простых задач

#### 3. Phi-4-mini-flash-reasoning (Самая компактная)
**Источник:** [Microsoft Blog](https://azure.microsoft.com/en-us/blog/reasoning-reimagined-introducing-phi-4-mini-flash-reasoning/)

**Преимущества:**
- Всего 3.8B параметров (~2.5GB VRAM)
- 92.45% Math-500
- 64K контекст
- До 10x быстрее inference

**Недостатки:**
- Обучена только на математике (не STEM в целом)
- 52.29% AIME 2024 (ниже Nemotron)

## Итоговая рекомендация

### Основная модель для дообучения: **Qwen3-8B-Instruct**

**Почему Qwen3-8B, а не Phi-4-mini или Nemotron:**

| Критерий | Qwen3-8B | Phi-4-mini | Nemotron-8B |
|----------|----------|------------|-------------|
| STEM (не только math) | ✅ Отлично | ❌ Только math | ⚠️ Math + Code |
| Программирование | ✅ 67.65 | ❌ Слабо | ✅ 71.1 LCB |
| Размер/Скорость | ⚠️ 8B | ✅ 3.8B | ⚠️ 8B |
| Fine-tuning готовность | ✅ Отлично | ✅ Отлично | ⚠️ Сложнее |
| Multilingual (русский) | ✅ Хорошо | ⚠️ Средне | ⚠️ Средне |
| Документация/Сообщество | ✅ Отлично | ✅ Хорошо | ⚠️ Новая |

### Модель-учитель для генерации данных: **Nemotron-Cascade-8B-Thinking** или **Cerebras API**
