## Краткое изложение полученных результатов

В данной работе разработана интеллектуальная обучающая система (ITS) для STEM-дисциплин, основанная на мультиагентной архитектуре и дообученной языковой модели Qwen3.5-9B. Система реализует сократический диалог с учениками 7–11 классов на русском языке. Каждая из шести поставленных задач успешно решена:

1. **Аналитический обзор ITS и методов RL для LLM**: проведен системный анализ существующих интеллектуальных обучающих систем (ALEKS, Khan Academy, Carnegie Learning) и современных методов обучения с подкреплением (RLHF, GRPO, DPO, STaR). Выявлено, что существующие решения не в полной мере используют сократический метод в сочетании с fine-tuning LLM на русскоязычных задачах.

2. **Архитектурное проектирование**: разработана трёхуровневая архитектура (Frontend → Backend → AI Core) с мультиагентным конвейером (Profiler → Planner → Tutor → Verifier), поддерживающим стриминг ответов в реальном времени через WebSocket и парсинг thinking-блоков.

3. **Реализация полного стека**: реализована готовая к деплою система с 25+ REST-эндпоинтами FastAPI бэкенда, фронтенда на Next.js 14 с поддержкой KaTeX для формул, интеграцией с Ollama для локального запуска модели. База данных (SQLite) содержит 4 таблицы для управления пользователями, сессиями, сообщениями и токенами обновления (JWT).

4. **Четырёхстадийный пайплайн дообучения**: реализованы все четыре стадии:
   - **GSPO**: тройная GDPO-нормированная награда (correctness 0,7 + format 0,15 + Socratic 0,15) с семью оптимизациями (Dr.GRPO, ReDit, GDPO, LEAD, Clip-Higher, Zero-Var, Seq-IS);
   - **KTO**: выравнивание через Kahneman-Tversky Optimization на основе unpaired preferences;
   - **DPO**: финальная полировка формата и стиля ответов;
   - **V-STaR-DPO**: composite scorer с весами correctness × 0,5 + PRM × 0,3 + no-spoiler × 0,2 на hard-subset из 426 задач (Phase 019, в разработке).

5. **Экспериментальная оценка**: создан бенчмарк из **3678 задач** (MGSM Russian 250 + ruMMLU STEM 3210 + Custom 218) с автоматической верификацией ответов (SymPy для математики, ChemPy для химии, regex для физики, exact match для CS и биологии).

6. **Система отслеживания знаний**: внедрена двойная модель (BKT + DKT) с формулой комбинирования mastery = 0,4·BKT + 0,5·DKT + 0,1·recency, граф навыков из 40+ компетенций, адаптивное управление сложностью.

## Достигнутые показатели

**Общая точность модели:**
- Исходная точность Qwen3.5-9B: **55,1%** (macro)
- После GSPO: **63,5%** (+8,4 п.п.)
- После KTO: **64,8%** (+1,3 п.п.)
- После DPO: **66,5%** (+1,7 п.п.)
- **Общий прирост: +11,4 п.п.**

**Точность по доменам (базовая модель):**
- Математика: 79,1%
- Физика: 74,4%
- Информатика: 46,5%
- Химия: 46,7%
- Биология: 28,6%

**Качество вывода:**
- Обрезка completions: снижена с **100% на 14,3%** благодаря ThinkingBudgetProcessor (бюджет 1500 токенов) с гарантированным завершением `</think>`

**Сократический диалог:**
- Доля вопросов в ответах: возросла с **34% до 61%** (после KTO-этапа)

**Архитектура и реализация:**
- **5 STEM-доменов**, покрытых корпусом обучения и оценки
- **4-стадийный пайплайн** обучения с progressive difficulty curriculum (easy → medium → hard)
- **Мультиагентная система** из 4 основных агентов + 2 вспомогательных (Affective, TaskGen)
- **25+ REST-эндпоинтов** FastAPI для управления пользователями, сессиями, аналитикой
- **Граф знаний** (Knowledge Forge) с 40+ навыками и их взаимосвязями

## Практическая применимость

Разработанная система готова к использованию русскоязычными учащимися 7–11 классов. Она демонстрирует следующие практические преимущества:

- **Локальный деплой**: все компоненты запускаются локально (Next.js + FastAPI + Ollama) без зависимостей от облачных API; модель работает в GGUF-квантизации Q4_K_M на GPU средней мощности (6 ГБ видеопамяти)
- **Реальная сократика**: система генерирует наводящие вопросы вместо прямых ответов, поддерживая метод problem-based learning
- **Персонализация**: модель ученика (BKT+DKT) адаптирует сложность и стиль вопросов к уровню знаний конкретного ученика
- **Многодоменность**: охватывает 5 дисциплин STEM, что позволяет ученикам изучать межпредметные связи
- **Потоковый ответ**: токен-за-токеном стриминг с парсингом thinking-режима даёт ощущение живого диалога

## Ограничения работы

Несмотря на достигнутые результаты, система имеет ряд ограничений:

1. **Размер модели**: Qwen3.5-9B — это относительно компактная модель, которая справляется с заданиями базовой программы, но испытывает затруднения при решении олимпиадных и нестандартных задач. Для существенного повышения точности требуется переход на 35B или большие модели.

2. **Масштабируемость базы данных**: использование SQLite обеспечивает портативность и простоту развёртывания, но не позволяет масштабировать систему на 1M+ одновременных пользователей. Для production-среды требуется миграция на PostgreSQL + горизонтальное масштабирование.

3. **Отсутствие пользовательского исследования**: оценка проведена исключительно на автоматическом бенчмарке (3678 задач). Не были задействованы реальные ученики и учителя для валидации педагогической эффективности, качества диалога и удобства интерфейса.

4. **Верификация ответов**: для естественно-научных предметов использованы эвристические методы (regex, tolerance-проверка), которые не гарантируют полную корректность. Например, в физике допускается численная ошибка ±5%, что может привести к ложным положительным результатам.

5. **V-STaR-DPO на стадии разработки**: четвёртая стадия пайплайна (Phase 019) всё ещё завершает обучение на full run. Результаты этого этапа будут интегрированы в финальное издание по завершении обучения на 84 composite-парах; ожидается дополнительный прирост точности за счёт composite scoring.

## Направления дальнейшего развития

Для усовершенствования и расширения возможностей системы предлагаются следующие приоритетные направления:

1. **Переход на модель большего размера**: миграция на Qwen3.5-35B при развитии ресурсов (использование quantization + distributed inference) даст ~5–10% дополнительной точности и лучше справится с олимпиадными задачами.

2. **User study с реальными учениками**: организация пилотного исследования с 50–100 учениками (7–11 классы) с целью оценки:
   - качества сократического диалога (рубрики для учителей)
   - удобства интерфейса и UX (SUS опросник)
   - влияния на долгосрочный прогресс в обучении
   - субъективной удовлетворённости учеников

3. **Gamification и мотивационная система**: внедрение механик (баллы, достижения, leaderboards), рейтинга навыков, социального обмена решениями для повышения вовлечённости.

4. **Мультимодальность**: поддержка распознавания рукописных формул (на базе DiffusionNet или EfficientNet) и загрузки фотографий задач — расширит удобство ввода для мобильных устройств.

5. **Масштабирование инфраструктуры**: миграция на PostgreSQL + Redis, горизонтальное масштабирование FastAPI (Kubernetes), deployment на облачные платформы (AWS, GCP) для обслуживания 1M+ пользователей.

6. **Расширение домена**: добавление разделов высшей математики (линейная алгебра, анализ), общей физики для вузов, специальные курсы (олимпиадная математика, подготовка к ЕГЭ).

7. **Интеграция с образовательными платформами**: подключение к системам управления обучением (LMS, например Moodle) для синхронизации данных ученика и встраивания туторской системы в существующие школьные инфраструктуры.

Реализация этих направлений позволит превратить текущий прототип в полноценное промышленное решение для персонализированного STEM-образования.
