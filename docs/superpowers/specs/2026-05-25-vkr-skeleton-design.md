## Контекст и проблема

`DIPLOMA_PLAN.md` обновлён под 4-stage pipeline (40 sources). Следующий шаг — материализовать план
в actual текст ВКР по университетскому образцу. Полная ВКR (80-100 стр) **слишком велика для одного
цикла** → декомпозиция на под-проекты: **каркас → Введение → Глава 1 → … → Заключение**, каждый со
своим spec→plan→write. Этот spec покрывает **первый срез — каркас**.

**Образец:** `ВКР(10) (3).docx` (кафедра ИУК3 «Системы автоматического управления», 73 стр).
Структура: титульник → АННОТАЦИЯ → ВВЕДЕНИЕ → главы (Heading 1: «Глава N. Название», Heading 2: «N.M.»)
→ ЗАКЛЮЧЕНИЕ → СПИСОК → ПРИЛОЖЕНИЯ. Стили: Times New Roman 14pt, justify, ГОСТ-поля.

**Готовый реюз-материал (для последующих циклов, НЕ этого):**
- `НИР_controlled_reasoning.docx` (~15 стр) → Главы 1.3-1.4 + 3.5-3.8 + 4.x (обучение модели)
- `Курсовой_проект.docx` (~12 стр) → Главы 1.1 + 2.3-2.4 (мультиагентная навигация)

## Goals

1. Создать `docs/diploma/ВКР_Сухацкий_2026.docx` — корректно отформатированный скелет
2. Сохранить всё форматирование образца (стили, поля, колонтитулы, шрифт)
3. Титульник + аннотация заполнены реальными данными (числа = placeholder)
4. Полная структура заголовков (Введение + 4 главы + Заключение + Литература + Приложения)
5. Reusable идемпотентный скрипт `scripts/build_vkr_skeleton.py`

## Non-goals (YAGNI)

- Проза глав (последующие per-chapter циклы)
- Рисунки/таблицы (только маркеры-placeholder)
- Числа аннотации N/M/K (TODO[meta], в конце)
- V-STaR результаты (TODO[V-STaR-final], как в плане)
- Авто-конвертация НИР/Курсового
- Финализация номеров страниц оглавления

## Section 1: Build approach & tooling

**Подход A — клонировать образец как template** (выбран из A/B/C).

Обоснование: стили OOXML живут в `styles.xml`, поля в `sectPr`, колонтитулы в `header*.xml` — **вне
body**. Можно очистить контент-параграфы body, сохранив `sectPr`, и все стили/форматирование образца
останутся доступны для `add_paragraph(..., style='Heading 1')`. Точный формат без ручной настройки.

- **Скрипт:** `scripts/build_vkr_skeleton.py` — reusable, идемпотентный (перезапуск пересобирает)
- **Вход:** `ВКР(10) (3).docx` (template стилей) + структура (хардкод из DIPLOMA_PLAN.md)
- **Выход:** `docs/diploma/ВКР_Сухацкий_2026.docx`
- **Механика:** открыть образец → сохранить `sectPr` → удалить body параграфы+таблицы → restore `sectPr`
  → построить титул + аннотацию + структуру через стили образца
- **Наследуется:** колонтитулы, поля, Times New Roman 14pt, стили Heading 1/2/3

## Section 3: YAGNI-границы
Не пишем прозу, не вставляем рисунки/таблицы (маркеры), не заполняем N/M/K, не трогаем V-STaR числа,
не конвертируем НИР/Курсовой, не финализируем номера страниц TOC.
