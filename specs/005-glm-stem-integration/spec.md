# Feature Specification: GLM-STEM Model Integration

**Feature Branch**: `005-glm-stem-integration`
**Created**: 2026-02-02
**Status**: Draft
**Input**: Интеграция REAP-pruned GLM модели (glm-stem-42exp) в MITS

## Overview

Интеграция оптимизированной REAP-pruned GLM модели (42 эксперта вместо 64) в систему MITS для улучшения производительности математического репетитора. Модель была специально откалибрована на STEM-датасете и сохраняет качество генерации при 33% сокращении параметров.

**Источник модели**: https://huggingface.co/Siesher/glm-stem-42exp-gguf

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Установка модели (Priority: P1)

Разработчик хочет быстро установить pruned GLM модель в локальное окружение через один скрипт, чтобы начать использовать оптимизированную модель для математического репетиторства.

**Why this priority**: Без установленной модели невозможно использовать систему MITS. Это блокирующий шаг для всей функциональности.

**Independent Test**: Можно протестировать запуском скрипта установки и проверкой `ollama list` на наличие модели `glm-stem-42exp`.

**Acceptance Scenarios**:

1. **Given** Ollama установлен и запущен, **When** разработчик запускает скрипт `scripts/install_glm_stem.sh`, **Then** модель скачивается с HuggingFace, создаётся Modelfile, и модель регистрируется в Ollama
2. **Given** модель уже установлена, **When** разработчик запускает скрипт повторно, **Then** скрипт обнаруживает существующую модель и предлагает переустановку или пропуск
3. **Given** недостаточно места на диске (<15GB), **When** разработчик запускает скрипт, **Then** выводится понятное сообщение об ошибке с требуемым объёмом

---

### User Story 2 - Автоматическое использование новой модели (Priority: P2)

Система MITS автоматически использует pruned GLM модель как основную для репетиторства, при этом сохраняя возможность fallback на оригинальную модель.

**Why this priority**: После установки модели система должна её использовать без дополнительной ручной настройки.

**Independent Test**: Запустить Gradio интерфейс и проверить в логах, что загружается модель `glm-stem-42exp`.

**Acceptance Scenarios**:

1. **Given** модель `glm-stem-42exp` установлена в Ollama, **When** запускается MITS, **Then** система использует её как primary model
2. **Given** модель `glm-stem-42exp` недоступна, **When** запускается MITS, **Then** система автоматически переключается на fallback модель (`glm-4.7-flash`) с логированием предупреждения
3. **Given** пользователь хочет использовать другую модель, **When** он указывает MODEL_NAME в .env, **Then** система использует указанную модель

---

### User Story 3 - Проверка работоспособности (Priority: P3)

Разработчик хочет быстро проверить, что установленная модель работает корректно для STEM-задач (математика, программирование, физика).

**Why this priority**: Без тестов нельзя убедиться в качестве интеграции и правильности работы pruned модели.

**Independent Test**: Запустить `pytest tests/test_glm_stem.py` и проверить прохождение всех тестов.

**Acceptance Scenarios**:

1. **Given** модель установлена, **When** запускается тест-сьют, **Then** все математические задачи решаются корректно (>90% accuracy)
2. **Given** модель установлена, **When** тестируется генерация кода, **Then** генерируется синтаксически корректный Python код
3. **Given** модель установлена, **When** тестируется русский язык, **Then** модель отвечает на русском при русскоязычном промпте

---

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: Система ДОЛЖНА предоставлять скрипт установки модели для Linux/macOS (`install_glm_stem.sh`) и Windows (`install_glm_stem.ps1`)
- **FR-002**: Скрипт установки ДОЛЖЕН скачивать GGUF файл с HuggingFace (выбор между Q4_K_M ~13GB и Q8_0 ~21GB)
- **FR-003**: Скрипт установки ДОЛЖЕН автоматически создавать Modelfile с оптимальными параметрами для GLM (temperature=0.2, top_k=2, repeat_penalty=1.0)
- **FR-004**: Скрипт установки ДОЛЖЕН регистрировать модель в Ollama командой `ollama create glm-stem-42exp`
- **FR-005**: Конфигурация проекта ДОЛЖНА использовать `glm-stem-42exp` как модель по умолчанию
- **FR-006**: ModelManager ДОЛЖЕН включать preset для `glm-stem-42exp-tutor` с корректными параметрами VRAM
- **FR-007**: Система ДОЛЖНА автоматически переключаться на fallback модель при недоступности primary
- **FR-008**: Проект ДОЛЖЕН включать тесты проверки работоспособности модели на STEM-задачах
- **FR-009**: Скрипт установки ДОЛЖЕН проверять наличие свободного места перед скачиванием
- **FR-010**: Скрипт установки ДОЛЖЕН поддерживать возобновление прерванного скачивания

### Key Entities

- **ModelConfiguration**: Конфигурация модели с параметрами (name, backend, purpose, ollama_model, estimated_vram_gb, temperature, etc.)
- **InstallationScript**: Скрипт установки с логикой скачивания, создания Modelfile, регистрации в Ollama
- **TestSuite**: Набор тестов для проверки STEM-capabilities модели

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: Установка модели занимает менее 30 минут на соединении 100 Mbps (скачивание ~13GB Q4_K_M)
- **SC-002**: Модель отвечает на математические вопросы с accuracy >90% на тестовом наборе из 20 задач
- **SC-003**: Время первого токена (TTFT) не превышает 2 секунды на GPU с 8GB VRAM
- **SC-004**: Скрипт установки успешно выполняется с первой попытки в 95% случаев на поддерживаемых ОС
- **SC-005**: Все существующие тесты проекта продолжают проходить после интеграции
- **SC-006**: Потребление VRAM на 20-30% меньше по сравнению с оригинальной 64-expert моделью

## Assumptions

- Ollama уже установлен в системе пользователя
- Пользователь имеет стабильное интернет-соединение для скачивания модели
- Минимальные требования: 16GB RAM, 8GB VRAM (или CPU-only режим с 32GB RAM)
- HuggingFace репозиторий `Siesher/glm-stem-42exp-gguf` доступен публично

## Out of Scope

- Обучение или дообучение модели
- Поддержка других форматов кроме GGUF
- Интеграция с облачными API (только локальный Ollama)
- Автоматическое обновление модели при выходе новых версий
